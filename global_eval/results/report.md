# Global evaluation: v1, v2, v3

Generated by `global_eval/run.py`. This module sits outside every model version and compares them on benchmarks none
of them owns. Each version is scored in its own process; the benchmarks only read the score matrices.

| Version | What it is |
|---|---|
| v1 | Weighted Jaccard over raw annotation sets (the original metric) |
| v2 | Logistic fusion of 12 modality cosines, fitted on curated relations (production model) |
| v3 | Drug-free neural + fusion static similarity, and a forecast stacker; production weights fitted through 2026 |

"Drug-free" rows hide the drug, drug-target and Open Targets modalities (v2) or approved drugs (v1), the view v3
works in, so v2 and v3 can be compared like for like.

## What the results say

- **v2 and v3 both clearly beat v1** on every benchmark. On paper-stated pairs, v2 gains +0.053 [+0.045, +0.061] in
  mean percentile of the partner (+0.081 on pairs with no curated relation); in the forward-in-time test, v3 static
  has about 4.6× v1's MAP (0.064 vs 0.014).
- **v3's static similarity is not better than v2's like for like.** On paper pairs the drug-free v3 − v2 difference is
  +0.002 [−0.003, +0.007] (a tie), and v2 with all modalities is slightly ahead (−0.006 [−0.012, −0.001]). In the
  forward-in-time test, v3 static is 0.064 against 0.061 for v2's architecture retrained on the same data. On the
  in-sample curated relations v3 is ahead on shared gene and shared drug and behind on siblings.
- **v3's gain is the forecast, not the similarity.** The stacker reaches 0.113 MAP on the forward-in-time test
  (+0.052 over retrained v2, p = 6e-26) but it is a different task: popularity alone (designation count) already
  reaches 0.070, and the stacker ranks paper-stated similar pairs *worse* than the static score. The graph that
  should go to users is the static similarity; the forecast is for repurposing candidates.
- **Papers' stated similarity is weakly tracked by every model** (Spearman 0.19–0.23, AUROC for "similar" vs
  "related but distinct" 0.63–0.64).

## Caveats

- Curated-relation numbers are in-sample for v2 and v3 (their production models were fitted on those relations).
- Paper-pair labels overlap curated relations for 58% of pairs; the "no curated relation" stratum is the cleaner test.
- The forward-in-time benchmark is v3's own ground truth (regulatory designations), which favours v3 by construction
  and reflects commercial development choices, not only biology.
- The forward-in-time run was reproduced on CPU with the shipped code. Its numbers differ slightly from `v3/README.md`
  (stacker 0.113 vs 0.113; static 0.064 vs 0.060; retrained v2 0.061 vs 0.056) because retraining is not bit-exact
  across hardware; all differences are inside the confidence intervals. `v2_shipped` is absent from this run because
  `v3/.data/v2_production_fusion.json` was not present, and the stacker chosen on validation was `v3_stacker`, not the
  README's no-history variant (reported alongside).
